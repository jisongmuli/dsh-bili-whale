# 刷 B 站鲸鱼娘 · 整合版

给 **DeepSeek Harness 桌面版**使用的鲸鱼娘插件。基于[原版刷B站](https://github.com/c1overzz/dsh-bili-scroll)，整合评论/私信回复、真实音画理解、表情图库、持续记忆和通用任务智能体。

**已有 DeepSeek Harness 的 Windows 用户：克隆仓库 → 退出宿主 → 双击 `安装.cmd` → 登录自己的账号。** 不需要复制作者电脑上的文件，不附带作者的密钥、账号、聊天或记忆。

```powershell
git clone https://github.com/jisongmuli/dsh-bili-whale.git
cd dsh-bili-whale
.\安装.cmd
```

也可以 **Code → Download ZIP**，解压到固定目录再安装。安装后保留该目录，插件会链接到它。**完整步骤：[安装与使用](docs/安装与使用.md)**。发给朋友时直接发仓库链接即可。

## 功能

- 评论/私信独立处理，主人优先；自己的投稿/动态收取顶楼评论及楼内直接回复，无需每条 @。
- 读取实际视频画面与原音轨，有无字幕均可；失败不假装看过。自动浏览08:00–23:00，每30分钟1个；手动立即运行不受间隔限制。
- 图片/动图理解、原图保存、语义检索、真实图片附件。图库从自己的资料开始，不复制作者的图片。
- 会话、好感度、观看证据、表达和角色形象长期保存；自己的成年版/Q版关联，其他AI娘分别辨认。
- 简单动作走既有代码；预设外的主人目标进入同一通用智能体环境，可检索记忆、处理文件、运行命令和使用浏览器。保留回执、去重及中断恢复。
- 按视频/动态/评论区暂停回复，主人消息豁免；可选每天随机主动搭话约10–16次。
- Gemini通过自己的官方Antigravity CLI登录；请求失败后可用宿主中自己的DeepSeek配置后备，付费后备每日合计2元保护。本地不设每日回复次数限制，服务端额度仍由自己的账号决定。

## 安装后

1. 双击 `登录模型.cmd`，在官方CLI完成自己的Google账号登录，关闭超额积分使用。账号可用模型/额度以实际服务为准。官方说明：[Antigravity CLI安装与认证](https://www.antigravity.google/docs/install?tab=cli)。
2. 宿主 **设置 → 刷B站**：先用机器人小号扫码，再点 **授权主人观看历史**，用自己的主账号扫码。两个UID由安装向导绑定，扫错账号不会替换登录。
3. 按需开启 **回复评论、回复私信、执行主人消息中的任务、主动找主人聊天、自动浏览/自动评论**。初装均关闭，完成登录后由本人启用；先测试一条私信和一个视频。

双击 `检查环境.cmd` 检查本地安装。所有密码、验证码和扫码都在使用者自己的电脑完成，不要发给别人。

Google账号额度不足时，点设置页 **切换 Gemini 账号**，或双击 **切换模型账号.cmd**，按官方登录窗口选择另一个账号。切换保留大肥鱼的记忆与B站身份，详见[手动切换Google账号](docs/切换Google账号.md)。

## 数据与更新

数据在 `%USERPROFILE%\.dsh\bili-duty`；自定义 `DSH_HOME` 时跟随它。程序与个人数据分开，升级不清空会话、好感度、图库、发送记录或费用账本。

更新：退出宿主 → 在本仓库目录 `git pull --ff-only` → 重跑 `安装.cmd` → 启动宿主。不要用同名npm原版覆盖整合版。更换绑定的B站主账号或机器人账号时使用新数据目录；切换Google模型登录继续使用原数据目录。

关机时机器人离线；开机后打开DeepSeek Harness即可恢复，不必开Codex、仓库或日常浏览器。登录过期则重新登录。

目前主要验证 Windows 10/11 + DeepSeek Harness 桌面版。见[故障排查](docs/故障排查.md)。通用任务开关允许绑定主人操作本机，启用前确认UID正确；金钱操作仍需确认。不含已取消的视频生成/Flow接入。
