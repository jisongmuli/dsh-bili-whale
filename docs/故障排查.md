# 故障排查

先双击 `检查环境.cmd`，再在设置→刷B站点“测一下”、看日志。不要把Cookie、OAuth、API key、完整私信或数据目录提交到Issue。

| 现象 | 处理 |
| --- | --- |
| 没有“刷B站”设置 | 确认安装desktop profile；退出托盘后重启；查看插件导入错误。不要装npm原版覆盖。 |
| 提示退出宿主 | 完全退出再运行，安装器不强制中断任务。 |
| Node或路径找不到 | 更新桌面宿主，重新选择实际exe或用AppPath指定。 |
| 依赖下载失败 | 检查网络后重试；也可在设置点装主依赖。Whisper是可选的大模型，不是音画理解必装项。 |
| CLI认证失败 | 双击登录模型.cmd，登录自己的Google账号；查网络、模型权限；API key不能替代CLI订阅登录。 |
| 超额积分被拒绝 | 官方CLI设置关闭useG1Credits，不开额外付费来绕过。 |
| 扫错账号 | 机器人入口用小号，历史授权用主账号；UID不符不会替换登录。 |
| 聊天但不做任务 | 开启主人任务，确认发信UID；未知任务需要CLI完整执行环境。 |
| 不主动聊天 | 开启主动聊天；只在08:00–23:00随机发，最近在聊天或任务进行中会让路。 |
| 不自动刷 | 开启自动浏览并授权主账号历史；每30分钟1个，空历史不编造偏好。 |
| 媒体识别失败 | 查CLI、网络、Python和浏览器依赖；没有实际画面不能把字幕回答当看完。 |
| DeepSeek后备暂停 | 每日合计2元保护，不清账本重试；Gemini入口仍可独立工作。 |
| 更换UID被拒绝 | 原目录属于原账号，新账号使用新的DSH_HOME，避免混用状态和回执。 |

程序不会在电脑关机后运行，需要长期在线就使用自己的常开电脑。仓库不提供服务器账号或共享登录。
