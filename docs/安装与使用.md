# 安装与使用

适合已有DeepSeek Harness桌面版的Windows用户。仓库包含增强插件、安装向导、Python依赖引导和基础人格，不需要作者的电脑、Codex会话或账号数据。

## 准备

- 两个B站账号：自己的主账号作为主人；给鲸鱼娘用的小号作为发言账号。空间地址 `space.bilibili.com/数字` 中的数字就是UID，不能填昵称。
- 自己可用的Google账号。CLI权限以账号实际可用为准，作者的Pro、免费额度与API key不会共享。
- 能访问Google及依赖站点的网络。如果原本使用本地代理，可在数据目录 `network-settings.json` 配置 `{"proxy":{"https":"http://127.0.0.1:端口"}}`，填写自己实际的端口。
- 需要DeepSeek后备时，在宿主模型设置配置自己的官方DeepSeek。未配置后备时，主通道失败就保留失败并等待恢复。

## 一次安装

1. 克隆或下载ZIP，解压到固定目录。路径可以有空格/中文，安装后不要移动。
2. 从托盘完全退出宿主。安装器不强制中断正在工作的任务。
3. 双击 `安装.cmd`，输入主账号和机器人小号两个UID。未自动找到宿主时，在选择器里选实际安装的 `DeepSeek Harness.exe`。
4. 安装器注册desktop插件，准备独立Python环境和依赖；CLI缺失时使用Google官方脚本安装。网络失败可重跑；已有状态不清零。
5. 双击 `登录模型.cmd`，在官方 `agy` 里完成自己的Google登录，然后退出CLI。密码、验证码留在自己电脑，不交给无人值守脚本。
6. 在官方CLI设置中保持 `useG1Credits` 关闭；启用超额积分时插件会拒绝该配置。
7. 启动宿主 **设置 → 刷B站**。先扫机器人登录二维码，用小号；再点 **授权主人观看历史**，用主账号。主账号历史登录不替换发帖账号。

官方文档：[Google Antigravity安装与认证](https://www.antigravity.google/docs/install?tab=cli)。需要手动安装CLI时，PowerShell运行官方命令：

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

默认CLI模型 `gemini-3.8-flash-low`。账号不支持时先用 `agy models` 查实际列表，再通过安装器的 `-Model '实际模型ID'` 参数指定。CLI模型保存于数据目录 `model-routing.json` 的 `antigravityModel`，更改后重启宿主。Gemini API key与订阅CLI登录是不同方式，本安装默认用CLI。

## 打开功能并验收

初装不自动发消息。完成登录后，按需要打开：

| 设置 | 作用 |
| --- | --- |
| 全天回复和大肥鱼对话的人 | 自己帖子顶楼、楼内直接回复及真正找她的消息 |
| 全天回复收到的私信 | 私信聊天，主人优先，不转动态 |
| 执行主人消息中的任务 | 代码预设及通用智能体目标，包含文件/命令/浏览器 |
| 主动找主人聊天 | 08:00–23:00随机约10–16次/天，离线不补发一堆 |
| 分散安排自动刷视频 | 08:00–23:00每30分钟1个，依据主账号历史 |
| 自动评论 / 转到动态 | 对实际看过的视频交流，原生转动态 |

先点“测一下”确认B站读取；主账号给小号发普通私信，确认回复；再分享视频要求观看；最后测试如查询UP主信息的小任务。没有实际核验不能只以口头答应算成功。

只有真实绑定UID有任务权限，别人昵称叫主人不算。通用任务启用后可驱动本机文件、命令与网页，只绑定自己控制的账号。投币按指令执行，充值/付款等金钱操作先单独确认。

## 图片与记忆

基础人格在数据目录 `AGENTS.md`；形象资料在 `character-memory.json`。自己的成年/Q版视为同一角色；不能只凭发色硬认，与真实后台模型无关。

图库初始为空，用主账号发自己有权使用的表情图，她会读取原图/动图并保存可复用图片。私人照片、聊天截图和普通私聊不自动作公共表情，仓库不复制作者的图片和私人资料。

## 重启、更新、卸载

- 开机后打开DeepSeek Harness即可，宿主运行时才在线；登录过期则重新扫码或登录CLI。
- 更新：退出宿主 → `git pull --ff-only` → 重跑安装器 → 重启。模板不覆盖已修改的记忆或人格。
- 不要删除链接着的仓库。换代码目录后，从新目录重跑安装器。
- 卸载可在宿主插件管理移除 `dsh-bili-scroll`。个人数据仍在 `.dsh/bili-duty`，先备份再自行处理，不清空数据来解决运行故障。

## 指定路径或非交互安装

```powershell
.\scripts\Install.ps1 -OwnerUid 123456 -BotUid 654321 -OwnerName '我的昵称' -BotName '大肥鱼' -AppPath 'D:\Apps\DeepSeek Harness\DeepSeek Harness.exe' -DshHome 'D:\MyWhaleData'
```

数字仅为示例，换成自己的UID。使用自定义DSH_HOME时，启动宿主也要跟随该目录；可在启动它的PowerShell中先设 `$env:DSH_HOME='D:\MyWhaleData'`。
