# 手动切换 Google 账号

大肥鱼沿用本机官方 Antigravity CLI 的 Google 登录。需要换账号时，可以使用已有 Google 账号的官方登录流程，不需要重装插件或重新登录 B站。

1. 保持 DeepSeek Harness 正在运行，在插件设置页点 **切换 Gemini 账号**；也可以双击仓库根目录的 **切换模型账号.cmd**。
2. 切换窗口先等待正在执行的任务完成。期间继续收取消息并保留队列，暂不启动新的模型任务。
3. 按窗口提示进入官方 CLI。若顶部仍显示原账号，输入 `/logout`；在官方浏览器页面选择另一个 Google 账号。需要授权时直接在 Google 页面完成，无需把密码或验证码发给大肥鱼。
4. 在 CLI 顶部核对账号，输入 `/exit` 返回切换窗口。若退出后尚未重新登录，可以输入 `R` 再次打开 CLI；完成后按回车验证。
5. 程序通过配置中的 Gemini Flash 模型发一个不带B站工具的小请求。验证通过后恢复任务。

切换完全由你发起，不会在额度不足时自动轮换账号。Google 官方的 App、CLI 和编辑器扩展共用本机登录，因此切换也可能影响这些程序的新会话。这里使用官方退出/登录，不自行导出或保存 Google 令牌，也没有第三方账号池。

切换过程保留 B站身份、会话、好感度、学习记忆、发送与操作回执、费用账本。超额 AI 积分保持关闭；原有 Gemini 优先、失败后才使用 DeepSeek（每日2元）的规则继续保留。

账号第一次用于官方 CLI 时可能需要完成授权。实际额度与模型使用资格取决于所选账号的方案。程序会测试当前登录是否能调用配置模型；账号是否选对请以官方 CLI 顶部显示为准。

交互式登录优先使用本机安装并由 Google 更新的官方 CLI，后台任务继续使用配置的工作版本；登录与后台共用已经配置的本机模型代理，避免浏览器能打开但 CLI 直接连接超时。若 CLI 异常退出，流程会停止，不会继续用旧登录验证并误报切换成功。遇到“Verify your account”时，需要在官方页面由账号本人完成手机／设备验证；OAuth 登录成功不代表账号已获得模型使用资格。

取消时在窗口输入 `Q`，或退出切换程序；未完成的验证不会被记为成功。若窗口意外关闭而后台仍显示切换中，先确认登录窗口已关闭，再在设置页点“窗口已关闭，恢复任务”，之后可重新打开切换入口。切换等待最多45分钟过期；已有任务不因切换状态被清空。

官方说明：[登录与退出](https://antigravity.google/docs/install?tab=cli)、[CLI命令](https://antigravity.google/docs/cli/reference/)。
