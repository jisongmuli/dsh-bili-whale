# 更新记录

## 0.3.2

改进后台生命周期：区分“宿主进程还活着”和“插件仍在运行”。插件释放后保留停止标记，避免旧状态中的PID阻止新后台接管；异常退出遗留的空锁可在保护期后恢复，存活的租约、旧版后台和新建中的锁继续受到保护，过期清理回调也不能释放新实例。

公开收信快照和私信队列查询改用只读状态事务，保留互斥读取，但不再为查询重复复制、序列化或保存整个会话文件。实际入队、发送和回执仍走原有写事务。

环境检查新增桌面插件登记、后台心跳和生命周期检查。文件仍在或PID存在，不再单独作为运行正常的依据；缺失登记时提示通过原安装流程恢复，不自动启用用户明确停用的功能。

新增7项生命周期和4项只读队列回归，覆盖进程死亡、旧宿主存活但插件已释放、部分锁、重复释放、查询异常、损坏状态与历史保留。

## 0.3.0

新增手动切换 Google 账号入口：设置页按钮和根目录的`切换模型账号.cmd`。先等待已有任务结束，再使用官方 CLI 登录；验证当前账号能调用配置模型后恢复任务，保留B站身份、记忆、队列与账本。

切换保持手动，超额积分关闭；不导出 Google 令牌，不自动轮换账号。支持重复入口去重、取消、重启后保留切换状态和超时恢复。详见[切换Google账号](切换Google账号.md)。

## 0.2.2

修复B站账户级评论限制被当作单条消息故障的问题。遇到12014（评论发送上限）、频繁请求等平台拒绝后，所有公开评论入口共用持久退避状态，队列继续收取消息，私信保持独立。到期后恢复调度；再次被平台拒绝时延长等待，成功后恢复正常。

平台限制不计入单条消息的失效次数，避免错误隔离正常来信；旧版因此产生的隔离会保留审计并恢复排队。原评论确已不可见、其他独立隔离和主人指定的暂停范围继续生效。暂停确认遇到平台限制时也保留等待，不会丢失或重复提交。

新增7项回归，覆盖恢复、去重、全账户限制、并发拒绝、旧记录迁移、私信独立，以及图片/动态评论和暂停确认入口。平台何时解除限制由B站决定；不会改用其他入口绕过限制。

## 0.2.1

修复历史视频任务被误报为观看失败的问题。“从看过/刷过的视频里选一个点赞收藏”只校验实际操作回执；包含“重新看一遍”的请求继续要求本轮调用视频理解。

历史观看声明可复用当前账号已保存、内容有效的真实音画分析。不会把来源评论区的视频当作另一个历史目标，也不会接受字幕、标题、损坏缓存、其他账号缓存或错误视频的证据。音画识别失败后清除本轮旧证据，成功重试后恢复。

补充自动回归，覆盖历史引用变体、新观看、历史与新观看混合、静音视频、错误缓存、失败恢复、成功回执、去重和主人权限边界。已有成功点赞/收藏不会因收尾误报而被重新提交。
